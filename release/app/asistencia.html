Asistencia Remota

Seguí estos 3 simples pasos para que podamos conectarnos a tu PC en minutos.

1

Descargá AnyDesk

Es la herramienta principal que usamos para realizar el soporte técnico de forma segura.

⬇ Descargar AnyDesk
💡 Tip: Si no ves la descarga, presioná Ctrl + J para ver tus archivos recientes.
¿AnyDesk te da error o no podés abrirlo?

Usá nuestra herramienta alternativa (RustDesk). Es ideal para PCs antiguas o cuando AnyDesk falla.

⬇ Descargar RustDesk
2

Ejecutá el programa

Hacé doble clic en el archivo que acabás de descargar. No hace falta instalar nada, el programa se abre directamente.

3

Enviános tu ID

Hacé clic en el botón de abajo para enviarnos tu ID por WhatsApp (y la contraseña si la aplicación te muestra una).

💬 Enviar mi ID por WhatsApp
🛑 IMPORTANTE: Dejá el programa abierto hasta que el técnico se conecte. Si lo cerrás, la conexión se perderá.
⚠️ ATENCIÓN: La imagen de abajo es solo ilustrativa. Por favor, no le saques captura a esta página.
🛡️

Conexión 100% Segura

Usamos cifrado de nivel bancario. Vos tenés el control total: ves todo lo que hace el técnico en tiempo real y podés cerrar la sesión cuando quieras con un solo clic.
