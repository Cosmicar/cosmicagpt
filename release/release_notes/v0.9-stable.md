# Release Notes - Cósmica v0.9 Stable

## Resumen Técnico
Esta versión marca la estabilización del núcleo del sistema Cósmica, integrando exitosamente la gestión de órdenes de servicio técnico con un módulo liviano de inventario y punto de venta (POS). El sistema está diseñado para operar de forma estática en GitHub Pages, delegando toda la persistencia y lógica transaccional a Firebase Firestore.

## Módulos Operativos
- **Órdenes de Trabajo**: Registro, edición, seguimiento público y ciclo de vida completo.
- **Inventario**: Catálogo de productos y repuestos, control de stock y alertas.
- **Ventas (POS)**: Carrito de compras, descuento de stock transaccional y generación de tickets.
- **Integración**: Los repuestos se reservan al agregarse a las órdenes y se descuentan físicamente al entregar el equipo.

## Estado Actual
- **Estabilidad**: Alta. Protegido contra dobles envíos y corrupción de tipos de datos.
- **Seguridad**: Reglas de Firestore aplicadas para separar producción de entornos de prueba (`_demo`).

## Limitaciones Conocidas
- No posee paginación en listas (puede impactar en rendimiento con muchos datos).
- La validación de unicidad de SKU no se realiza en tiempo real en el cliente.

## Próximos Pasos
- Implementar paginación en tablas.
- Desarrollar la Fase 4 de reportes financieros y márgenes.
