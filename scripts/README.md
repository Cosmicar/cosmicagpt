# Herramientas de la web pública

Ejecutar `npm run build` desde la raíz. No requiere dependencias externas.

El build valida separación de proyectos, genera y valida páginas provinciales, sincroniza contactos y marca, comprueba activos oficiales y crea `dist` con una lista explícita de archivos públicos. Verifica las referencias locales y el sitemap antes de terminar.

GitHub Actions y Vercel ejecutan el mismo comando. La salida no incluye documentación, herramientas, dependencias ni plantillas.

Los scripts de Firebase retirados pertenecían al sistema histórico y permanecen recuperables en Git. No se opera ninguna base de datos desde este repositorio.
