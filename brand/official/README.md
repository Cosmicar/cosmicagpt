# Activos oficiales de Cósmica

Estado: fuente visual canónica vigente desde 2026-08-04.

## Regla definitiva del símbolo

- C limpia, sin acento ni trazo flotante.
- El logotipo se compone con la C carmesí y “osmica”.
- En texto escrito, la marca conserva su ortografía: Cósmica.
- No utilizar ni reconstruir versiones anteriores.

Las huellas SHA-256 y dimensiones se controlan en `scripts/check-brand-official.mjs`. Cualquier sustitución no autorizada hace fallar la compilación antes de publicar.
